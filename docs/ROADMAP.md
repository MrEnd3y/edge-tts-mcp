# Возможности edge-voice-mcp для Hermes

Цель: небольшой локальный MCP для подготовки речи и связанных файлов.
**Hermes выбирает действия и доставляет результат; MCP синтезирует и проверяет.**
Это не новый движок синтеза: используется Microsoft Edge TTS через `edge-tts`.
Не требуется установленный браузер Edge, но требуется доступ к сервису Microsoft.

## Уже проверенная основа (0.1.0)

- Асинхронный синтез без `stream_sync()` и `nest_asyncio`.
- Инструменты `tts` и `list_voice`, выбор языка через конкретный голос.
- Фильтры голосов по locale и полу; скорость, высота, громкость.
- MP3 и OGG/Opus через внешний FFmpeg.
- Ограничение времени, проверка формата/длительности, уникальные имена,
  очистка при ошибках и отмене, безопасные сообщения об ошибках.
- Настраиваемая папка вывода и путь FFmpeg, изоляция от встроенного TTS Hermes.
- CLI/пакет, запуск через Python, pip/venv, pipx или uv/uvx.
- Офлайн- и онлайн-тесты на Windows, Python 3.12 и 3.14.

## Реализованное расширение (0.2.0)

Ниже — согласованные и реализованные возможности. Отчёт о проверках и
их ограничениях находится в [VALIDATION.md](VALIDATION.md). Список возможностей
не является обещанием доступности Microsoft или проверкой всех возможных текстов.

### 1. Голоса разных языков

- Без фильтров получать весь доступный список, не только русский язык.
- Выбирать конкретный голос из ответа Microsoft, например Светлану, Дмитрия или Aria.
- Фильтровать по языку/региону и полу; искать по имени и метаданным.
- Получать дополнительные сведения о голосах, **если сервис их предоставляет**.
- Постранично получать каталог, когда полный ответ модели не нужен.
- Не выдавать категории/описания голоса за гарантированную поддержку эмоций или SSML.

### 2. Настройки и профили речи

- Задать голос, скорость, громкость и высоту по умолчанию на сервере.
- Переопределять их в конкретном вызове `tts`.
- Необязательные профили: обычные настройки сервера, повествование,
  быстрое уведомление, медленное чтение.
- Профили — предустановки параметров, **не актёрские эмоции/клонирование голоса**.
- Явные параметры запроса важнее параметров профиля.

### 3. Аудио для разных сценариев

- MP3 для файлов, обычного прослушивания и монтажа.
- OGG/Opus для подготовки голосового Telegram; требуется FFmpeg с libopus.
- В ответе — успех/ошибка, локальный путь, формат, MIME, размер,
  длительность и фактические настройки голоса.
- Файл не отправляется автоматически. Hermes использует свои инструменты доставки.

### 4. Длинные тексты

- Повысить лимит с 5000 до 100000 символов.
- Использовать UTF-8-безопасное внутреннее разбиение `edge-tts`, а не
  изобретать параллельные несогласованные фрагменты и ручную склейку.
- Получать один аудиофайл и сквозные временные метки.
- Сохранять общий тайм-аут: длинный запрос не должен зависать бесконечно.
- Большой допустимый размер **не гарантирует** завершение в 45 секунд.
  Для долгой задачи Hermes повышает дедлайн (до 300 с) и тайм-аут клиента
  либо делит исходную задачу на меньшие части.

### 5. Субтитры SRT/VTT — необязательные

- Создавать субтитры **к синтезируемой речи**, а не распознавать чужую запись.
- По выбору возвращать SRT или WebVTT.
- Группировать слова в короткие фразы по временным событиям синтеза.
- Не создавать субтитры по умолчанию.
- Если сервис не вернул пригодные метки — вернуть аудио с явным предупреждением,
  не придумывать времена из длины текста.

### 6. Метки слов — необязательные

- По запросу создавать JSON со словом, началом и концом в миллисекундах.
- Источник — `WordBoundary` Microsoft, не приблизительная оценка.
- Применение: подсветка текста, караоке-подобное отображение, монтаж,
  синхронизация элементов видео и дальнейшая обработка субтитров.
- Это не транскрипция и не независимая проверка качества произношения.
- Не возвращать тысячи слов в MCP-ответе: вернуть путь к JSON и число слов.

### 7. Осведомлённость нейронки о возможностях

- Сохранить имена `tts` и `list_voice`.
- Добавить read-only `get_capabilities`: форматы, требования FFmpeg,
  лимиты, значения по умолчанию, профили и доступность дополнительных файлов.
- Дать модели понятные описания и правила выбора параметров.
- Обычная озвучка: только аудио. Telegram voice: OGG без дополнительных файлов.
- Субтитры и метки включаются только когда нужны задаче пользователя.
- Сервер может жёстко запретить дополнительные файлы настройкой,
  независимо от решения модели.
- Результаты должны позволять модели различать ошибку синтеза и успешное
  аудио с предупреждением об отсутствии меток.

### 8. Надёжность и выпуск

- Проверить новые сценарии на Python 3.12 и 3.14.
- Тестировать отключённые дополнительные файлы, неверные/отсутствующие
  события, Unicode, длинные тексты, ошибки записи, отмену и очистку.
- Не публиковать частично готовый набор файлов как успешный результат.
- Дополнить инструкции для pip/venv, pipx и uvx.
- Вести Git и делать коммиты по завершённым изменениям.
- GitHub/PyPI-публикация — отдельный шаг после выбора имени/авторства и проверки лицензий.

## Примеры выбора возможностей

| Задача | Что запрашивает Hermes |
| --- | --- |
| «Озвучь ответ» | Аудио с настроенным голосом, без меток и субтитров |
| «Ответь голосовым в Telegram» | OGG/Opus; затем Hermes отдельно отправляет файл |
| «Прочитай по-английски женским голосом» | Каталог голосов en/Female → `tts` с выбранным ShortName |
| «Озвучь статью» | Длинный текст и подходящий тайм-аут |
| «Нужны озвучка и субтитры для ролика» | MP3 + SRT/VTT |
| «Подсвечивай каждое слово» | Аудио + JSON с метками слов |

## Не входит в текущий объём

- Прямая отправка в Telegram и хранение токена бота внутри MCP.
- HTTP-сервис, OAuth, публичные ссылки и облачные загрузки.
- Воспроизведение на звуковой карте сервера.
- Распознавание существующих аудио/видео, перевод, монтаж.
- Клонирование голоса, обещания эмоциональных стилей, произвольный SSML.
- Автоматическое удаление успешных файлов без согласованной политики хранения.
- Подмена работающего встроенного TTS Hermes или изменение других профилей.

Эти направления можно обсуждать отдельно. Они не обязательны для работы
локального stdio MCP и не должны усложнять простой сценарий «создать речь».
